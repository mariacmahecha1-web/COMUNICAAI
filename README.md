# ComunicaAI

Agente de IA de comunicación organizacional y marketing estratégico, diseñado para apoyar campañas de sensibilización del Sistema Integrado de Gestión (SGI).

## Qué hace

- **Consultor IA y chat:** resuelve consultas estratégicas sobre campañas y comunicación interna.
- **Estrategias y cronograma:** genera estrategias de campaña a partir del nombre, la fecha clave, el dolor a resolver y el KPI principal.
- **Métricas e informes:** analiza indicadores de campañas y entrega 3 insights clave con propuestas de refuerzo.
- **Gemelo digital:** muestra el contexto y las instrucciones con las que opera el agente.

## Cómo usarlo

1. Abre la página publicada en GitHub Pages.
2. Haz clic en **Configurar API Key** e ingresa tu clave de Google Gemini (se obtiene gratis en Google AI Studio).
3. Empieza a usar cualquiera de los módulos.

## Seguridad

La API Key **no está en el código**. Cada persona la ingresa desde el navegador y se guarda solo en ese navegador. Nunca pegues tu clave dentro de `index.html` ni la subas al repositorio.
