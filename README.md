# ComunicaAI

Agente de IA para diseñar, ejecutar y medir campañas de sensibilización del Sistema Integrado de Gestión (SIG): SST, gestión ambiental, seguridad de la información, calidad y convivencia laboral.

**Abrir el agente:** https://mariacmahecha1-web.github.io/COMUNICAAI/

## Módulos

- **Consultor:** chat con memoria de la conversación que responde usando tu base de conocimiento, tus métricas y las próximas fechas.
- **Estrategias:** estrategia completa con objetivo SMART, concepto creativo, cronograma por semanas e indicadores.
- **Piezas y copys:** textos listos para Outlook, Teams, WhatsApp, afiches o intranet, con propuesta visual para diseño.
- **Calendario SIG:** fechas internacionales clave por componente y tus propios hitos (auditorías, comités). Desde cada fecha puedes planear una campaña.
- **Métricas:** registro editable de campañas con cálculo de resultado vs. meta, tarjetas de KPI, exportación a Excel e informe ejecutivo con 3 insights.
- **Base de conocimiento:** política, objetivos, normas, campañas, públicos, identidad y documentos de consulta que el agente usa en cada respuesta.

## Privacidad

Este repositorio es público, por eso **no contiene información interna**. La base de conocimiento, las métricas, las fechas propias y la API Key se guardan solo en el navegador de quien usa el agente. Para llevar tu información a otro computador usa *Descargar respaldo* e *Importar respaldo*, y guarda ese archivo en un lugar privado.

## Cómo empezar

1. Abre el agente y haz clic en **Configurar API Key**. Pega tu clave de Google Gemini (gratis en Google AI Studio).
2. Ve a **Base de conocimiento** y completa o importa tu información.
3. Usa cualquiera de los módulos.
